# TonyPi 运动标定记录

本记录使用 Tag 0、`36h11`、边长 `0.10 m`，每段动作前后都将云台置于
`PWM1=1500/PWM2=1435`。位移不是直接相减 Tag 在相机中的 `t`，而是由两次
`camera <- tag` 刚体变换计算相机原点在 Tag 坐标中的变化，再转换到动作前相机坐标。
因此表中的数值是相对于静止 Tag 的米制相对运动，不是世界坐标绝对位移或编码器真值。

坐标约定：`forward=+Z`、`lateral=+X`（图像右方）、`vertical=+Y`（OpenCV 向下）；
`yaw` 使用动作前相机坐标中的水平旋转角。

## 当前结论

这些样本还不能安全地组成动作预测模型：左右横移及转向的单次/多次结果样本
不足，`left_move ×1` 的横向和 yaw 方差已经很大，且前进样本在较长动作后丢失目标。
因此导航暂不硬编码上述均值，也不把一次动作调用次数当作物理步数。后续应先提高
重复次数、验证 Tag 姿态解的稳定性，并在每段动作设置最大预算和视觉进度 watchdog
后再用于闭环预测。
